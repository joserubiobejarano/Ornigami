## Current Sentry residual-copy guidance

The current [backup help article](https://www.sentry.help/en/articles/13965019-how-frequently-is-data-backed-up), applicable to all Sentry users, states that production event backups expire 30 or 90 days after creation depending on data type. It does not map each data class to a window or prove physical expiry for the inspected account. This is current published guidance, separate from the older security PDF that was not adopted.

The [source-map article](https://www.sentry.help/en/articles/13964397-what-is-the-retention-period-for-source-maps), dated 11 August 2026, describes a 90-day idle period: processing an event with an artifact or re-uploading it resets the period. After the idle period, the artifact becomes eligible for deletion; this is not a fixed creation-to-erasure guarantee. Source artifacts therefore require separate review from the Developer event lookback. Private `sentry/current-backup-help.txt` retains the reviewed policy text without ephemeral attachment URLs.
